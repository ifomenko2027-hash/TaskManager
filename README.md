# Практична робота №21

Проєкт: TaskManager

Тема: Індивідуальний проєкт. Вибір теми та постановка задачі. Архітектура застосунку. Визначення MVP.

Застосунок дозволяє створювати, редагувати та зберігати завдання.

MVP:
- створення завдання;
- редагування;
- видалення;
- перегляд списку;
- збереження у JSON.

Архітектура:
UI: MainWindow
Logic: TaskManager, TaskService
Data: TaskRepository, JsonStorage
